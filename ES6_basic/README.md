# ES6 Basic

This project covers the fundamentals of ECMAScript 6 (ES6), the sixth edition of the ECMAScript standard.

## Learning Objectives

- What ES6 is
- New features introduced in ES6
- The difference between a constant and a variable
- Block-scoped variables
- Arrow functions and function parameters default to them
- Rest and spread function parameters
- String templating in ES6
- Object creation and their properties in ES6
- Iterators and for-of loops

## Requirements

- All files are interpreted/compiled on Ubuntu 20.04 LTS using node 20.x.x and npm 9.x.x
- Code is tested using the Jest Testing Framework
- Code is analyzed using the linter ESLint
- All functions must be exported

## Setup

npm install

# ES6 Promise

Project on JavaScript Promises: `then`, `resolve`, `catch`, the `Promise`
static methods, `throw` / `try`, the `await` operator, and `async` functions.

## Requirements

- Interpreted/compiled on Ubuntu 20.04 LTS using node 20.x.x and npm 9.x.x
- All files end with a new line
- Code uses the `.js` extension
- Tested with Jest (`npm run test`)
- Verified against lint with ESLint
- All functions must be exported

## Tasks

| File | Description |
| ---- | ----------- |
| `0-promise.js` | `getResponseFromAPI` returns a resolved Promise |
| `1-promise.js` | `getFullResponseFromAPI` resolves or rejects based on a boolean |
| `2-then.js` | `handleResponseFromAPI` appends then/catch/finally handlers |

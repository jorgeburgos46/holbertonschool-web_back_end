# Python - Async Comprehension

## Description
This project covers async generators and async comprehensions in Python.

## Requirements
- Editors: `vi`, `vim`, `emacs`
- Ubuntu 20.04 LTS, `python3` (version 3.9)
- All files end with a new line
- First line of all files: `#!/usr/bin/env python3`
- Code follows `pycodestyle` (version 2.5.x)
- All files must be executable
- All functions and coroutines must be type-annotated
- All modules and functions must have documentation

## Tasks

| Task | File | Description |
| ---- | ---- | ----------- |
| 0 | `0-async_generator.py` | Coroutine `async_generator` that yields 10 random numbers between 0 and 10, waiting 1 second between each |
